# 参与贡献 · Contributing

感谢你对拟物书架的兴趣。

**目前暂不接受代码合并请求（pull request）。** 项目处于早期，代码由作者本人维护，这样可以保持设计一致，也保留以后调整许可方式的余地。

非常欢迎：

- **提 issue**：bug、使用中遇到的问题、功能建议。
- **分享你的提示词和模型组合**：哪个模型、哪套提示词在你的书架上效果好，欢迎在 issue 里贴出来（请去掉 API 密钥和个人信息）。
- **晒书架**：用它搭了自己的书架？欢迎在 issue 里分享截图或链接。

报告安全问题请不要公开提 issue，发邮件到 hello@shelfsake.com。

将来如果开放代码贡献，会先在这里说明贡献者许可协议（CLA）的要求。

---

Thanks for your interest in Skeuomorphic Bookshelf.

**Pull requests are not being accepted for now.** The project is early and maintained by its author, which keeps the design consistent and leaves room to adjust licensing later.

Very welcome:

- **Issues** — bugs, problems you run into, feature ideas.
- **Prompt and model recipes** — which model and prompts work well on your shelf (please remove API keys and personal details).
- **Your shelf** — built one? Share a screenshot or link in an issue.

Please report security problems privately to hello@shelfsake.com rather than in a public issue.

If code contributions open up later, the contributor license agreement (CLA) requirements will be described here first.
